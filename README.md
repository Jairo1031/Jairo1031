## Problem Overview
Graphical models provide a framework for representing complex probability distributions through graph structures. This assignment explores:
- **Bayesian Networks**: Directed acyclic graphs representing conditional dependencies among random variables
- **Hidden Markov Models**: Temporal probabilistic models for sequential data with hidden states

These models are fundamental to machine learning, enabling applications in natural language processing, computer vision, bioinformatics, and decision-making systems.

## Bayesian Network Details
### Structure
The Bayesian Network implemented in this project models conditional dependencies between variables using a directed acyclic graph (DAG). Each node represents a random variable, and edges encode probabilistic relationships.

### Key Components
- **Nodes**: Random variables with associated probability distributions
- **Edges**: Conditional dependencies between variables
- **Conditional Probability Tables (CPTs)**: Quantify the strength of relationships

### Inference Methods
- Variable elimination for exact inference
- Probability queries for computing marginal and conditional distributions
- Evidence propagation through the network

## Hidden Markov Model (HMM) Details
### Model Architecture
The HMM implementation captures sequential dependencies with:
- **Hidden States**: Unobservable states that evolve over time
- **Observations**: Observable outputs generated by hidden states
- **Transition Probabilities**: Likelihood of moving between hidden states
- **Emission Probabilities**: Likelihood of observations given hidden states

### Algorithms Implemented
- **Forward Algorithm**: Computing observation probabilities
- **Viterbi Algorithm**: Finding the most likely sequence of hidden states
- **Baum-Welch Algorithm**: Parameter estimation from observed data
